What it arrived at

—

The best of the latest generation. A score is against that generation's opponents, so it cannot be compared with one from another generation — a population that learns to fly before it learns to shoot scores superbly until guns appear, then far less while getting better.

Measured against one opponent

Every design of every generation, one against one against the same opponent under the same seeds — the one number here that means the same thing in generation one and generation four hundred. Fought afterwards and never during, or a run would learn to beat that one opponent.

A run is decided entirely by its seed: the same settings give the same run, and any match in it can be fought again from the record. Watching a battle: space to pause, full stop to single-step, F to re-fit, N for another match. Scroll to zoom, drag to pan.
